彼からプロポーズを受ける
引き寄せ解説

「結婚したい」とノートに書いているのに、彼から結婚の話が出ない。
友達の指輪写真を見て、夜にLINEを何度も開いてしまう。
そんな夜に使うページです。

今夜やることは2つだけです。
①ノートに書く文を1つ決める
②その文を、明朝からも同じまま7日間書く

今夜やること

ノートを開いて、①②③を1行ずつ書きます。書き終わったらノートを閉じて、彼のトーク画面は開きません。

1

いま起きていることを1行書く
例：付き合って1年。結婚の話はまだ一度も出ていない。

2

いまの気持ちを1行書く
例：友達の指輪写真を見て、自分だけ遅れている気がする。

3

明朝からも書く1行を決めて書く
例：私は、彼との日々を穏やかに楽しみ、すでに愛されている。

明日からも書くのは、③で決めた文だけです。
彼が既読をつけても、デートの予定が入っても、入らなくても、③の文は書き換えません。

「プロポーズして」と書くと、なぜ遠ざかるか

結婚したい気持ちが悪いのではありません。
でも「プロポーズして」「決断して」と書くと、書いた直後に彼のLINEを見に行きやすくなります。

ノートに「プロポーズして」と書いたあと

「早くプロポーズして」と書く → 既読だけついて返信が遅い → 「嫌われたのかな」とトークを開き直す → 翌朝また「決断してほしい」と書き直す

友達の婚約報告を見たあと

友達の婚約報告を見て焦る → 「◯歳までに指輪が欲しい」と書く → 次のデートで結婚の話を探る → 彼が黙ると落ち込む

彼の態度でノートの文が毎日変わるとき

態度が冷たい日だけ「本気になって」に変える → 優しい日は「このままでいい」に変える → ノートの文が、彼の顔色で毎日変わる

こう書くと、LINEを見に行きやすい

プロポーズして／結婚して／決断して／◯月以内に

書いたあと、「返事来たかな」「態度変わったかな」と確認しに行きやすい文です。

こう書くと、ノートを閉じやすい

私は、彼との日々を穏やかに楽しみ、すでに愛されている
私は、私にふさわしい約束の指輪を、すでに受け取っている

彼に「して」と頼まない文です。書いたら閉じて、7日同じまま続けます。

先に変わるもの／あとに見えるもの

指輪やプロポーズは、いちばんあとに見えやすいです。
先に変わるのは、今夜のスマホの使い方です。

1
今夜のノート 「して」と頼む文か、「すでにそうなっている」文か。ここで、夜にLINEを開き直す回数が変わります。
2
会ったときの会話 会う回数、話しやすさ、将来の話の出方など、二人の会話が先に変わりやすいです。
3
指輪・プロポーズ 指輪を選びに行く、ひざまずく——見える結果は、あとから来ることが多いです。

1週間書いて指輪が来なくても、失敗ではありません。
先に見るのは、「夜にLINEを開き直す回数が減ったか」「デートで結婚の話を探らなくなったか」です。

今夜の書き方（4行）

交際中で、まだプロポーズ前の例です。自分の言葉に置き換えてください。
いちばん大事なのは、④の「明朝からも書く1行」です。

1いま起きていること

事実だけ。予想は混ぜない。

彼とは交際している。結婚の話はまだ具体的にしていない。会うのは月に数回。

2いまの気持ち

不安も寂しさも、ここに出す。

結婚のタイミングが不安。彼の本気度がわからない。周りは結婚しているのに、自分だけ取り残された気がする。

3本当はどう扱われたいか

「彼に〇〇して」ではなく、「私はすでにこう扱われている」で書く。

私は、自然体のまま大切にされ、安心して二人の時間を過ごせている。

4明朝からも書く1行

いちばん大事。既読がついても、文は変えない。

私は、彼との日々を穏やかに楽しみ、すでに愛されている。

指輪や場所を入れたいとき

ゆいさん型（指輪）

私は、私にふさわしい約束の指輪を、愛する人とともに、すでに受け取っている。

レナさん型（場所）

私は、私を選んでくれる人と、世界でいちばん美しい場所で誓いを交わしている。

書いたあとに守ること

A

連絡が来ても来なくても、④の文は変えない。

B

書いたらノートを閉じる。何度も読み返さない。

C

毎日だいたい同じ時間に、5分だけ書く。

7日間書く1行の例

迷ったら、指輪のお願いより先に書いてください。
「◯月までに指輪が欲しい」だけ書くと、書いたあと彼の態度を確認しに行きやすくなります。

書いて続ける例

私は、彼に選ばれていて、二人の関係を穏やかに楽しめている

彼に「プロポーズして」と頼まない文です。

書いて続ける例

私は、私を大切にする人と、幸せな未来を一緒に歩いている

指輪のお願いではなく、会っているときの扱いの文です。

書いて続ける例

私は、私にふさわしい約束の指輪を、すでに受け取っている

指輪を書くなら、「すでに受け取っている」形にします。ブランド名は書かなくて大丈夫です。

催促しやすい文 → こう直す

直し方

早くプロポーズして
→ 私は、彼に選ばれていて、すでに愛されている

お願い文だと、書いた直後に彼の態度を見に行きます。

直し方

◯月以内に指輪が欲しい
→ 私は、私にふさわしい約束の指輪を、すでに受け取っている

期限だと、友達の報告を見るたび焦ります。

直し方

彼を本気にして／態度を変えて
→ 私は、大切にされ、安心して二人の時間を過ごせている

彼を変える文ではなく、「私はすでに大切にされている」文に戻します。

こう書いたら、すぐ直す7つ

下の文に近づいたら、直し方の文に戻してください。
直したあとは、最低7日間同じ文のまま続けます。

①

プロポーズして／結婚して

直し方：私は、彼に選ばれていて、すでに愛されている

②

◯月以内に／◯歳までに

直し方：期限を外して、「すでに受け取っている」文にする

③

彼の態度を変えて／本気にして

直し方：彼へのお願いをやめて、「私は大切にされている」文にする

④

あの指輪でなければ／このブランドでなければ

直し方：私にふさわしい形で、すでに受け取っている

⑤

彼を離婚させて（複雑恋愛）

直し方：相手の家庭を壊す文は書かない。自分の愛される文に戻す

⑥

連絡してからプロポーズして

直し方：連絡のお願いとプロポーズを混ぜない。未来の誓いの文だけ書く

⑦

連絡の有無で、毎日の1行を変える

直し方：選んだ文を7日固定。既読や態度で揺らさない

7日間のやり方

初めてなら、④の1行だけ決めて、7日間同じまま書いてください。
①②③は後から足して大丈夫です。

1日目

明朝からも書く1行だけ書く。ほかは書かなくてよい。書いたら閉じる。

2〜5日目

同じ文を書く。変えない。指輪が来なくても失敗にしない。見るのは「夜にLINEを開き直す回数が減ったか」だけ。

6日目

まだ同じ文。友達の婚約報告を見ても、「早くして」に戻さない。

7日目

事実・気持ち・「どう扱われているか」を1行ずつ足してもよい。でも、明朝からも書く1行は変えない。

2週目以降：事実→気持ち→「どう扱われているか」→毎日の1行、の順で1枚に書く。毎日の1行は2週間同じままでOKです。

音信不通のとき：7日間は毎日の1行だけでOK。「連絡してからプロポーズして」は書かない。連絡が来ても、すぐ文を変えない。

途中でやりがちなこと

1週間書いて何も起きないとき

1週間書いて何も起きない → 「プロポーズして」に変えてしまう

彼の態度が冷たいとき

彼の態度が冷たい → ノートを書くのをやめてしまう

友達が結婚したと聞いたとき

友達が結婚した → 焦って「早くして」に戻してしまう

書いてから現実が動くまで、時間が空くことがあります。
そのあいだに文を変えると、また「返事来たかな」とトークを開き直す夜に戻りやすいです。だから、選んだ1行を変えずに続けます。

3人の短い実例

状況は違っても、やったことは近いです。
彼を動かそうとしない。お願い文にしない。同じ文を続ける。

ゆいさん｜付き合い1年・結婚の話は遠い

彼を動かそうとせず、指輪の文を「すでに受け取っている」形で書き続けた。

私は、私にふさわしい約束の指輪を、愛する人とともに、すでに受け取っている。

ある日、彼が指輪を選びに誘い、行き着いた先がノートのイメージと同じ指輪だった。

レナさん｜音信不通のあと

「連絡して」と書きたくなる夜も、「連絡して」とは書かず、未来の誓いの文を3ヶ月続けた。

私は、私を選んでくれる人と、世界でいちばん美しい場所で誓いを交わしている。

3ヶ月後に連絡が戻り、憧れの場所でプロポーズを受けた。

サキさん｜「もう無理」と諦めかけた夜

焦って婚活を殴りに行かず、「大切にされる結婚」を書いていた。

私は、世界でいちばん大切にされる結婚を、すでに受け取っている。

友人紹介で出会い、1年以内にプロポーズ・挙式へ進んだ。

今夜やること（もう一度）

ノートを開く。
明朝からも書く1行を1つ決める。
書いたら閉じる。
彼の既読や態度で、文を変えない。

状況別の文が欲しいときは、特典①のフレーズ集も使えます。今夜書くのは、いちばんしっくりくる1行だけです。

あわせて使う

不安型／依存型／回避型の診断結果と、状況別フレーズ集があると、今夜の1行が選びやすいです。

特典①｜状況別10フレーズ集へ まだ診断していない方 愛され周波数タイプ診断へ 無料・約2分 ／ 別ページで開きます
