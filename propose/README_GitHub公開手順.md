`https://knttnhtt9k-beep.github.io/ordernote/propose/`

※ 診断・特典①と同じリポジトリ `knttnhtt9k-beep/ordernote` の **サブフォルダ `propose/`** に置く（ルートに上書きしない）

## アップロード手順

1. GitHub で `ordernote` リポジトリを開く
2. `Add file` → `Upload files`
3. このフォルダ内の次を、リポジトリ直下に **`propose/` フォルダごと** アップロード  
   - `index.html`  
   - `styles.css`  
   - `images/cover.png`
4. Commit
5. 数分後に上記URLを開く（キャッシュなら `?v=2` を付ける）

## ローカル確認

```bash
cd propose
python3 -m http.server 8765
# http://localhost:8765/
```
