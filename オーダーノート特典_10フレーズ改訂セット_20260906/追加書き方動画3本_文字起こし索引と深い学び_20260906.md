## 動画2｜オーダー健康診断（補正まとめ）

- 日付を書く理由＝振り返り用。直近1〜3ヶ月で「オーダーした回数」を数える  
- 不安の吐き出し・アウトプットだけの行はカウントしない  
- カウント対象：宇宙へのオーダー（周波数／エネルギー／物質など）  
- **ポイント制**  
  - 小さなオーダー（自己完結・すぐ届きそう）＝1点  
  - 人生を動かす大きなオーダー（引っ越し・パートナー・仕事の方向など）＝5点  
  - 大きなものは1回で終わらず、周波数→象徴化→現実化で最低3回書く  
- **目安**  
  - 0点：危機感（ジムに通って筋トレしてない状態）  
  - 3点以下：少ない。月5点以上は強制的に取る  
  - 合格ラインイメージ：月10点（小5＋大1 など）  
  - ベスト：10〜20点  
  - 30点超で「小さいオーダーだらけ」→オーダー依存／大きな望みから逃げている可能性  
- 3週間以上書いていない期間＝人間がんばり・苦しみの時期になりやすい  
- 小さく見せかけて大きく数えない。ダメならダメと認めて修正する

## 動画3｜ジャーナリング（補正まとめ）

- 頭の中をバーッと出してノイズ0／真空にする書き方  
- **思考から書かない。身体感覚から書く**（眠い・首がこる 等）→思考・感情へ移る  
- ノーストップで、思いつくまで書き続ける  
- 理想は毎朝すぐ。1ページ〜3ページ  
- 目的はフロー状態 → 潜在意識の本音・ノイズ原因がアウトプットされる → 上澄みが消える  
- 頭の中の**占有率が高いこと**が人生を支配する（例：既読待ち・返事しなきゃ）  
- 占有率を下げて真空をつくると、本当にやりたいことが入ってくる  
- オーダーノートの前段として使える（ブレインノートと組み合わせ可）

## 既存6本＋今回3本を一本にした「深い学び」

### 書く順番（恋愛特典に落とす版）

1. **（任意・推奨）ジャーナリング** … 既読・不安・追いたい気持ちをノートに全部出す（オーダーにしない）  
2. **願望をガバッと書く** … 偽願望でも書いてよい。余白2〜3行  
3. **7〜10日寝かせる** … 残った情熱だけが本命候補  
4. **周波数** … 残った願望を全部叶えている自分の気分に名前をつける（愛される周波数）  
5. **象徴化** … その周波数にふさわしい関係・持ち物・日常（3〜7日寝かせる）  
6. **現実化オーダー** … 象徴化から残った1行だけを書く（今回の10フレーズはここ用）  
7. **引き寄せたことも日付で書く** … エネルギー／情報／物質どれでもよい。1個動いたら次を書く

### 効く文章／効かない文章

| 効かない | 効く |
|---|---|
| 彼への結果要求（連絡して／戻って） | すでに愛されている側の事実文 |
| 不足・焦り・試しLINEの延長 | 受け取っている感覚が映像になる文 |
| 気分だけで毎日同じ願いを連打 | 寝かせたあと残った1行だけ |
| 小さなオーダーの量産で安心 | 周波数→象徴化が入った質の高い1行 |

### インスピレーションノートとの接続（ユーザー提示＋動画3）

| | オーダーノート | インスピレーションノート |
|---|---|---|
| 役割 | 書くだけで願望を引き寄せる | オーダーした答えが即座に見つかる |
| 概念 | 周波数・象徴化・現実化 | **オーダー＋自動書記** |
| 前提 | どんなノート・ペンでも可 | 書く場所／状態／ペン／ノートに強く依存 |
| 状態 | 心が動くデフォルト＋周波数 | **自分＝神さま**。魂は全未来を知っている。理想の世界線を選ぶ情報を下ろす |
| 前段 | ジャーナリングで真空 | 真空＋神さま状態が前提になりやすい |

→ 特典の10フレーズは当面 **オーダーノートの「現実化1行」** に特化。  
→ 「答えが即座に降りる」体験は、ジャーナリングで占有率を下げたあとに起きやすい、と接続する。

## 10フレーズ改訂の設計ルール（再現性）

1. **彼への動詞命令を入れない**（連絡／態度／復縁の要求ゼロ）  
2. **主語は私。すでに叶っている側の現在進行**  
3. **場面が見える**（スマホ／予定／会話／安心の身体感覚のいずれか）  
4. **タイプ別で「書いていい」になる文は、そのタイプの占有率を下げる側**  
   - 不安型：既読を見なくても安心している側  
   - 依存型：尽くさなくても受け取っている側  
   - 回避型：近づいても逃げず受け取っている側  
5. **1行だけ書く。書いた日は追い確認しない**（健康診断の「質」と一致）
