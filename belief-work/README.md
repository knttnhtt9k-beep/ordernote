# 思い込みを手放す14日ワーク

共通URLから受講者が氏名、メールアドレス、4桁の暗証番号を設定し、次回はメールアドレスと暗証番号でログインします。メール送信とGoogle OAuthは使用しません。メールアドレスの所有確認はありません。

Apps Script の Code.gs と Index.html に配置し、WORK_DOCUMENT_ID と WORK_SHEET_ID をスクリプト プロパティで設定します。参加者タブの E 列にメール、G/H 列に失敗回数と制限終了時刻を保存します。運営シートの共有は運営担当者に限定します。

受講者向けに公開する前に、登録、ログイン、重複登録の拒否、失敗回数の制限、Day 1 の提出、翌日0時の解放、日別タブとまとめへの反映を確認します。
