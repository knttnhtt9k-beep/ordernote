# 思い込みを手放す14日ワーク

このフォルダーは既存のセッションワークとは独立した Apps Script ウェブアプリです。

1. 新規の Apps Script プロジェクトを作成し、Code.gs と Index.html を追加します。
2. プロジェクトの設定で WORK_DOCUMENT_ID（14日ワーク原稿の ID）と WORK_SHEET_ID（運営用シートの ID）をスクリプト プロパティに設定します。運営用シートには「参加者」「ワークまとめ」「Day 1」〜「Day 14」タブが必要です。
3. 運営用シートの共有先を運営担当者に限定します。参加者タブに氏名・参加者コード・4桁の暗証番号が入ります。
4. 実行ユーザーをデプロイ所有者とし、受講者がアクセスできるウェブアプリとして新規デプロイします。受講者にはこの新しい /exec URL を案内します。
5. テスト参加者で提出、再ログイン、まとめ、先頭が0の暗証番号、翌日0時の解放を確認します。

参加者コードは同姓同名を区別するために自動発行されます。同じブラウザではコードを自動入力します。別端末ではコードと暗証番号が必要です。
「ワークまとめ」の確認ポイントは提出済みの日付の組み合わせで自動表示されます。生成AIによる回答分析は未接続です。
